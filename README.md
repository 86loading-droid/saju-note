# 지현석의 사주풀이

가족·친구용 개인 사주풀이 웹앱 (단일 `index.html`). v2.3 — 간판·아바타를 아기 이나 일러스트로 교체, 온화한 색감(크림·캐러멜) 적용, 관계 상태 반영, 지나간 대운 제외.

- 앱 주소: https://86loading-droid.github.io/saju-note/
- v2 명리학 13개 장: 인트로(가면·본성·욕망), 기초 설계도, 1장 상징(납음·수호신·액운), 2장 돈, 3장 인연, 4장 일, 5장 건강, 6장 인생 흐름(대운 그래프), 7장 개운법, 8장 가족·관계, 9장 배움, 10장 월별 흐름, 11장 궁금증 해결소(주제별 적기)
- v2 일본 사주학: 산명학 인체성도(10대주성·12대종성), 천중살(6유형·시기), 구성기학(본명성·월명성·9년 주기·연반 길방위), 두 관점 비교
- 일러스트: 오행 순환도, 근묘화실 나무, 십이운성 고리, 인생 그래프, 인체성도, 구성 연반, 천중살 고리 (SVG) / 사진: Wikimedia Commons(저작자·라이선스 표기)
- v1 기능: 사주 원국(십성·지장간·12운성·신살), 13개 풀이 영역(오행·십성·십이운성·신살·귀인·재물·연애결혼·직업·건강·대운·5년 세운과 삼재·AI 질문), 궁합, 오늘의 운세, 명부(브라우저 저장 + 공유 링크 + 명부 코드)
- 계산: lunar-javascript 1.7.7(MIT) 절기·음력 변환. 연·월주는 절입 시각(절대시간) 기준, 일·시주는 출생지 지방시 기준. 한국 표준시 이력(1908–1911, 1954.3.21–1961.8.9 UTC+8:30)과 서머타임(1948–1960, 1987–1988) 반영. 대운수는 3일=1년 반올림.
- AI 질문(월령에게 묻기)은 Claude 앱 안에서 연 경우에만 동작하며, 이 공개 주소에서는 자동으로 숨겨집니다.
- 명부 데이터는 각 기기 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다.
